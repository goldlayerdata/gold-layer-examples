# Examples

One folder per technique, named after the post or short it belongs to (kebab-case), for example
`pareto/`, `variance/` or `time-intelligence/`.

```text
examples/<topic>/
├── README.md        what it shows, which dataset, link to the post
├── *.dax            the measures, ready to paste
├── <topic>.Report/  the report page (PBIR), bound to the dataset's shared model
└── img/             screenshots and SVGs used on the site
```
